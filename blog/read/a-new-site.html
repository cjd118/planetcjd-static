A new site!

Published: 9 years ago php

Do not adjust your monitor. It is actually a new site.

Here's what is new:

  • Built using Laravel. I am reserving judgement on Laravel for now as a simple blog site is not really a true test for it.

  • New asset handling - one of the advantages of using Laravel is the handling of CSS and JS has improved and things like Sass and ES6 can now be used

  • An actual backend - I have made a simple back end so I no longer have to use Windows Live Writer to post blogs. I'm not sure if Windows Live Writer even still exists.

  • A different design - but yes, I've kept the awesome logo.

As with the previous launch (6 years ago - wow), I am going to add new features to the site over time. I just felt it was time to launch.
